# Cloud Application

pip install -r requirements.txt.

Учебный проект по дисциплине
«Управление работами и разработка программного обеспечения облачных систем».

## Возможности

- серверное приложение FastAPI;
- REST API для управления сервисами;
- CRUD-операции;
- автоматическая документация OpenAPI;
- модульная организация проекта.

## Запуск

Активировать виртуальное окружение и выполнить:

python -m uvicorn app.main:app --reload

Сохраните файл.

## Основные адреса

- `/` — основная информация;
- `/status` — состояние приложения;
- `/services` — управление сервисами;
- `/docs` — интерактивная документация API.

## Структура проекта

- **routers/** — содержит маршруты API и обрабатывает HTTP-запросы пользователей.
- **schemas/** — хранит схемы данных для проверки входящей информации и формирования ответов API.
- **services/** — содержит основную бизнес-логику приложения и выполняет обработку данных.
- **data/** — предназначен для хранения данных, используемых приложением.

## Состояния сервисов

Для облачных сервисов поддерживаются следующие состояния:
- `running` – сервис работает;
- `maintenance` – сервис находится на обслуживании;
- `stopped` – сервис остановлен.
