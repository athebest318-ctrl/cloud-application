# Отчёты по ЛР 30–33 и 35

Выполнил: Дьяченко Артем. Дата проверки: 15 ноября 2026 года.

Редактируемые тексты находятся в этом каталоге; PDF — в `reports/labs_30_35`. Протоколы проверок — в `evidence/labs_30_35`. Каждый отчёт содержит цель, реализацию, фактические результаты, схемы и ответы на все контрольные вопросы.

Проверено: 40 тестов, Ruff 0.17.4, форматирование 50 файлов, compileall, Docker image 0.8, миграции и контейнерные сценарии 201/403/503/504 с восстановлением. Тесты покрывают также преобразование upstream-ошибки в 502. ЛР 35 повторена в отдельном Ubuntu-контейнере с systemd как PID 1, worker от nobody; проверены отказ 42, восстановление и очистка.

Ограничение ЛР 32: фактическая отладка выполнена в pdb. VS Code был открыт и подготовлен, но графическое управление остановлено нажатием Esc; требуемые скриншоты его панелей не получены. Эта часть в отчёте не отмечена как выполненная.
