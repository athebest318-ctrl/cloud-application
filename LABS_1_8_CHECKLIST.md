# Выполнение лабораторных работ 1-8

## ЛР 1. Подготовка среды

- Проект находится в `C:\Users\User\Desktop\College\LR`.
- Виртуальное окружение создано в `.venv`.
- Зависимости сохранены в `requirements.txt`.
- Приложение запускается командой `python -m uvicorn app.main:app --reload`.

## ЛР 2. Первое серверное приложение

- Настройки приложения вынесены в `app/config.py`.
- Реализованы маршруты `/`, `/status`, `/about`, `/course`.
- Название приложения: `Cloud Application`, версия: `1.0`.

## ЛР 3. Сетевые параметры запуска

- Приложение можно запускать на разных адресах и портах:
  `--host 127.0.0.1 --port 8000`,
  `--host 127.0.0.1 --port 8080`,
  `--host 0.0.0.0 --port 8000`,
  `--host 127.0.0.1 --port 9000`.
- Исходный код при смене сетевых параметров не меняется.

## ЛР 4. HTTP-запросы

- Реализованы GET-маршруты для проверки через браузер и `curl.exe`.
- Для несуществующих адресов FastAPI возвращает `404 Not Found`.
- Для неподдерживаемого метода на существующем пути возвращается ошибка метода.

## ЛР 5. REST API и CRUD

- Реализован ресурс `services`.
- Поддерживаются операции:
  `GET /services`,
  `GET /services/{service_id}`,
  `POST /services`,
  `PUT /services/{service_id}`,
  `DELETE /services/{service_id}`.
- Пустой список сервисов корректно обрабатывается при создании нового объекта.

## ЛР 6. Документация API

- Swagger UI доступен по адресу `http://127.0.0.1:8000/docs`.
- ReDoc доступен по адресу `http://127.0.0.1:8000/redoc`.
- OpenAPI JSON доступен по адресу `http://127.0.0.1:8000/openapi.json`.
- Для методов добавлены `summary`, `description`, теги и описание ошибок `404`.

## ЛР 7. Модульная архитектура

- Маршруты вынесены в `app/routers`.
- Схемы вынесены в `app/schemas`.
- Бизнес-логика вынесена в `app/services`.
- Временные данные вынесены в `app/data`.
- Системные методы вынесены в `app/routers/system.py`.
- Реализован маршрут `/service-count`.

- Создан файл `PROJECT_TASKS.md`.
- Описаны требования `REQ-01` - `REQ-05`.
